# Atraium 0.3.3 Preview 2

Atraium 0.3.3 Preview 2 is a small reliability update for [Preview 1](https://github.com/daemosofchaos/Atraium-Preview/releases/tag/v0.3.3-preview.1). It is recommended for all Preview 1 users.

## What changed

- Fixed an issue where changing the Chat provider for an active Workspace could apply for the first message and then revert to the previous provider on later turns.
- Workspace and Room provider selections now remain consistent throughout the conversation without requiring the Workspace to be reloaded.
- Android can now connect to explicitly configured local HTTP services, including compatible local model and image-generation servers that do not provide HTTPS.

## Platforms

- **Windows desktop:** recommended preview experience.
- **Android:** early sideloaded preview for Android 7.0 or later, supporting arm64-v8a devices and x86_64 emulators.
- **Web, macOS, and iOS:** not included in this preview.

## Important notes

- This is preview software and may contain breaking issues.
- Use unencrypted HTTP connections only with services and networks you trust. Prefer HTTPS when exposing a service beyond your private local network.
- Local image generation requires a separately installed and configured compatible server and model.
- Generated image quality, editing support, available dimensions, and generation speed depend on the selected model, workflow, server, and hardware.
- Support is best-effort.
