# Atraium 0.3.3 Preview 3

Atraium 0.3.3 Preview 3 is a usability and attachment-access update for [Preview 2](https://github.com/daemosofchaos/Atraium-Preview/releases/tag/v0.3.3-preview.2). It is recommended for all Preview 2 users.

## What changed

### Better right-click support

- Restored standard right-click actions in the composer, including **Copy**, **Cut**, **Paste**, **Select all**, and spelling suggestions where supported by the device.
- You can now select text in a chat message and right-click to **Copy selected text** or **Ask about this**.
- **Ask about this** adds the selected text as a quote to the current composer draft and focuses the composer. It does not send a message automatically.

### Assistant access to attachments

- The assistant can now use supported text attachments supplied with a message, including Markdown, plain text, structured data, configuration files, logs, and common source-code files.
- The assistant can also find and read supported files attached earlier in the current Room or Workspace when needed.
- Large supported attachments are read in smaller sections, allowing the assistant to work with longer files without overwhelming the conversation.
- Existing document support remains available for compatible PDF, Word, Excel, and PowerPoint attachments.

## Platforms

- **Windows desktop:** recommended preview experience.
- **Android:** early sideloaded preview for Android 7.0 or later, supporting arm64-v8a devices and x86_64 emulators.
- **Web, macOS, and iOS:** not included in this preview.

## Important notes

- This is preview software and may contain breaking issues.
- Attached content may contain inaccurate or untrusted instructions. Review important outputs before acting on them.
- The assistant can access only supported attachments in the active Room or Workspace; it does not gain unrestricted access to local files merely because an attachment is available.
- Local image generation requires a separately installed and configured compatible server and model.
- Support is best-effort.
