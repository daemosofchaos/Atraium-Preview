# Atraium 0.3.4 Preview 5

Atraium 0.3.4 Preview 5 improves PDF composition and image-editing reliability. It is recommended for [Preview 4](https://github.com/daemosofchaos/Atraium-Preview/releases/tag/v0.3.4-preview.4) users who create PDF documents or use GPT Image 2 for image edits.

## What changed

### Better PDF cover pages and document images

- Fixed a cover-page layout issue where the coloured accent bar could overlap text at the left edge of the page.
- Cover-page artwork can now be placed before or after the eyebrow, title, subtitle, summary, or author and date details.
- Cover-page images support uploaded chat images as well as local files, remote images, and generated images.
- Added optional images to repeated PDF headers and footers.
- Header and footer images can be sized precisely and used alongside header or footer text.
- PDF document tool guidance now includes a complete creation reference, making it easier for assistants to discover available PDF layouts, blocks, image options, and unsupported arrangements.

### Clearer Word document creation guidance

- Word document tool guidance now includes a complete creation reference for both standard and advanced document creation.
- The reference describes supported document structures, image options, code blocks, headers, footers, templates, and unsupported arrangements.

### More reliable GPT Image 2 edits

- Fixed image edits using **GPT Image 2** failing when an input-fidelity preference is supplied.
- Atraium now automatically omits that unsupported optional setting for GPT Image 2 while preserving it for compatible image models.

## Platforms

- **Windows desktop:** recommended preview experience.
- **Android:** early sideloaded preview for Android 7.0 or later, supporting arm64-v8a devices and x86_64 emulators.
- **Web, macOS, and iOS:** not included in this preview.

## Important notes

- This is preview software and may contain breaking issues.
- Regenerate an affected PDF document after updating to apply the cover-page and header/footer improvements.
- Existing documents are not changed automatically.
- Support is best-effort.
