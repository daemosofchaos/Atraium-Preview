# Atraium 0.3.2 Preview 1

Atraium 0.3.2 Preview 1 improves conversation continuity, history access, and multi-step tool reliability. It follows [0.3.1 Preview 5](https://github.com/daemosofchaos/Atraium-Preview/releases/tag/v0.3.1-preview.5).

## Highlights

### More complete conversation context

- Prompt context is now loaded independently from the visible message page, allowing assistants to use a larger recent working history while the conversation interface remains fast and responsive.
- Loading older messages in the interface no longer changes or limits the assistant's prompt working set.
- Recent attachments retain their full capabilities, while older attachment references are represented efficiently without loading every historical file into memory.

### Full persisted history lookup

- Conversation-history search and lookup actions can now access the complete persisted Room and Workspace thread, including messages older than the currently visible page.
- History lookup continues to respect the active Room and Workspace boundary.
- Older tool activity, attachment references, and message details are easier for compatible assistants to locate during long-running work.

### More reliable tool workflows

- Improved conversation compaction preserves recent tool calls and results more effectively.
- Tool output is shortened only when necessary to stay within the selected model's available context.
- Compatible Responses API providers can now recover when a just-completed response is temporarily unavailable to the next tool-continuation request.
- Recovery retries the continuation without repeating the completed tool action.

## Platforms

- **Windows desktop:** recommended preview experience.
- **Android:** early sideloaded preview for Android 7.0 or later, supporting arm64-v8a devices and x86_64 emulators.
- **Web, macOS, and iOS:** not included in this preview.

## Important notes

- This is preview software and may contain breaking issues.
- Available history, context, and tool capabilities depend on the selected model, provider, Room, Workspace, and configured access.
- Model context limits still determine how much conversation material can be included in an individual request.
- Support is best-effort.
