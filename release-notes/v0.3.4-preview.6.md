# Atraium 0.3.4 Preview 6

Atraium 0.3.4 Preview 6 is a command-execution reliability update for [Preview 5](https://github.com/daemosofchaos/Atraium-Preview/releases/tag/v0.3.4-preview.5). It is recommended for Preview 5 users who use local command tools.

## What changed

- Improved timeout handling for local command execution.
- Timed-out or cancelled command requests now stop their related processes more reliably.
- Commands whose output streams remain open no longer keep Atraium waiting indefinitely after the configured timeout.
- Common timeout-setting formats are now handled more consistently across local command tools.
- Timeout results now provide clearer information when a command could not be confirmed as stopped.

## Platforms

- **Windows desktop:** recommended preview experience.
- **Android:** early sideloaded preview for Android 7.0 or later, supporting arm64-v8a devices and x86_64 emulators.
- **Web, macOS, and iOS:** not included in this preview.

## Important notes

- This is preview software and may contain breaking issues.
- Background commands intentionally return without waiting for completion.
- A timeout value of `0` or less intentionally allows a command to run without a time limit.
- Support is best-effort.
