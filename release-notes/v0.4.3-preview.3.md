# Atraium 0.4.3 Preview 3

Atraium 0.4.3 Preview 3 enables full file-tool access by default, adds Room and Workspace controls for directory-access requests, and makes those requests easier for assistants to discover.

## Fixes and improvements

### File access that fits the Workspace

- **Full file-tool access by default.** Assistants can read and write paths that Atraium can access using your operating-system permissions, without requesting every project folder first.
- **Choose a directory-request workflow.** Enable **Require root access requests** under **File-system access** in Room settings to require a request before file tools use paths outside the listed roots. The assistant cannot switch off your saved requirement.
- **Workspaces inherit the Room setting**, with an option to override it. Leave **Use Room file-access setting** enabled to inherit, or turn it off to choose the requirement for that Workspace.
- **Requested folders stay with the correct Workspace.** Grants are remembered when returning to that Workspace, without carrying another Workspace's requested folders into it.
- **Improved Gateway discovery for directory requests.** Searches such as **request root access**, **grant folder access** and **access to a folder** prioritize the directory-request action. Queries about the current access state continue to favor inspection instead.

### Assistant identity

- **Corrected assistant naming in Basic Chat Completions mode.** Instructions now use the selected assistant's name rather than a fixed default name.

## Platforms

- **Windows desktop:** recommended preview experience.
- **Android:** early sideloaded preview for Android 7.0 or later. Video inference runs through a hosted service or remote GPU server, not on the phone.
- **Web, macOS and iOS:** not included in this preview.

## Important notes

- This is preview software. Back up important data before upgrading; provider access, availability and capabilities vary.
- **Review the new file-access default before starting sensitive work.** Enable **Require root access requests** in the relevant Room or Workspace if you want the directory-request workflow. Saved changes apply before the next assistant request, not to tools already running.
- A directory request covers the folder and its contents. On Windows it is granted immediately, **not through an additional approval dialog**. This does not grant administrator or Android device-root privileges, bypass OS storage permissions, or sandbox terminal commands and subprocesses. Review overwrite, deletion and other consequential actions separately.
- **Stopping chat or navigating away does not cancel video generation.** Use **Cancel video** for an explicit cancellation request. Hosted cancellation is best-effort and may still be billed; running ComfyUI jobs are not interrupted server-wide.
- Mobile suspension can pause tracking and downloads. Reopen the original message to reconnect. Playback depends on device memory and codec support.
- Audio and image-reference support vary by preset. ComfyUI requires installed models and compatible nodes; model licensing terms apply. Hosted generation sends prompts and selected references to the provider.

## Costs and credentials

**Atraium is a bring-your-own-model application.** It does not include provider credentials, model credits, a token allowance or hosting. Providers set their own prices, limits and terms; you are responsible for charges incurred through the accounts and services you configure.

- Chat, research, images, video, speech and paid integrations can incur separate charges. A consumer ChatGPT, Claude or Gemini subscription does not necessarily include API credits.
- Longer research, coding and independent-assistant tasks can involve multiple model and tool calls. Set **provider-side budgets, quotas and hard spending limits where available** before starting. Alerts and Atraium's usage display are not hard spending controls.
- Local models can avoid hosted per-token charges, but hardware, electricity, storage and rented GPU servers can still cost money. A local Chat model does not make other hosted capabilities free.
- Keep API keys private. Do not include credentials in prompts, screenshots or public bug reports.

**Provider-side billing records are authoritative.** Review [Token usage and provider billing](https://github.com/daemosofchaos/Atraium-Preview/blob/main/TOKEN-USAGE-AND-BILLING.md) before connecting paid services.
