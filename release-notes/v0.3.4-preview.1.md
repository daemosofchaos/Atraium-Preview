# Atraium 0.3.4 Preview 1

Atraium 0.3.4 Preview 1 introduces primary local computer tools and built-in productivity tools for email and calendars.

## Highlights

### Local Computer Tools

- The primary tools for working with local files and commands are now presented as **Local Computer Tools** rather than coding-only tools.
- Use these tools for everyday work such as reading and updating text files, searching folders, creating files, applying coordinated changes, and running local commands.
- The core tool set remains familiar: **Read**, **Write**, **Edit**, **Glob**, **Grep**, **Bash**, and **apply_patch**.
- Local Computer Tools are available directly to the assistant by default, making routine file and command work faster and more natural across general, research, writing, and planning Workspaces.
- You retain full control: a Room or Workspace can move the whole family, or an individual tool, to gateway access or disable it entirely.
- Existing tool-routing preferences are preserved when updating.

### Built-in Email and Calendar tools

- Added built-in **Email** and **Calendar** tool families to Atraium’s tool catalog.
- The assistant can prepare a prefilled email draft with recipients, subject, and message content. Atraium opens the draft in your mail app; **you review and send it yourself**.
- The assistant can inspect available calendar capabilities, list calendars, search events where supported, and prepare a calendar event for review.
- Creating a calendar event opens the platform calendar editor. **Events are never saved automatically**; you review and save them yourself.
- Email and Calendar tools use the same Room and Workspace routing controls as the rest of the tool catalog.

## Platforms

- **Windows desktop:** recommended preview experience.
- **Android:** early sideloaded preview for Android 7.0 or later, supporting arm64-v8a devices and x86_64 emulators.
- **Web, macOS, and iOS:** not included in this preview.

## Important notes

- This is preview software and may contain breaking issues.
- Local Computer Tools operate only within the folders and access permissions you have granted to Atraium.
- Email drafts and calendar events always require your review in the platform application before they are sent or saved.
- Calendar availability and read access depend on the device, platform support, and granted permissions.
- Support is best-effort.
