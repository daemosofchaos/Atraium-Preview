# Atraium 0.3.4 Preview 4

Atraium 0.3.4 Preview 4 is a small document-generation bug-fix update for [Preview 3](https://github.com/daemosofchaos/Atraium-Preview/releases/tag/v0.3.4-preview.3). It is recommended for Preview 3 users who create Word or PDF documents from structured specifications.

## What changed

- Fixed generated **Word documents** failing when a code block supplies its source through the dedicated code field.
- Fixed the same issue in generated **PDF documents**, including code blocks placed inside highlighted or grouped content areas.
- Code snippets now render correctly in standard and advanced Word document compositions.
- Existing specifications that use the earlier text-based code-block format remain supported.

## Platforms

- **Windows desktop:** recommended preview experience.
- **Android:** early sideloaded preview for Android 7.0 or later, supporting arm64-v8a devices and x86_64 emulators.
- **Web, macOS, and iOS:** not included in this preview.

## Important notes

- This is preview software and may contain breaking issues.
- Regenerate an affected Word or PDF document after updating to apply the fix.
- Existing documents are not changed automatically.
- Support is best-effort.
