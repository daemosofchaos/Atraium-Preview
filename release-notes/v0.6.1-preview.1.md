# Atraium 0.6.1 Preview 1

Atraium 0.6.1 Preview 1 introduces **response steering for GPT-6** and clearer wording across the app.

## Features and improvements

### Update a response while it's running

Add a missing detail or change direction without stopping the assistant and starting again. Type your instruction and choose **Send update** while GPT-6 is responding.

Available with supported OpenAI and Azure OpenAI connections.

### Also improved

- Clearer setup and settings guidance.
- Easier-to-read Supervisor status labels.

## Platforms

- **Windows x64:** recommended preview experience, with installer and portable options.
- **Android:** early sideloaded preview for Android 7.0 or later, supporting arm64-v8a devices and x86_64 emulators. Local model servers must be reachable from the device; heavy image and video generation runs on a connected service or server, not on the phone.
- **Web, macOS and iOS:** not included in this preview distribution.

## Important notes

- **Back up important data before upgrading.** Preview versions may change settings or data formats. Backup restore replaces the data covered by the archive rather than merging it; review the confirmation and expect to re-enter API keys.
- **Live updates support text only.** To send Skills, selected text or files, wait for the response to finish or stop it first.
- **Supervisor delegation is opt-in.** Set team limits and give specialists separate responsibilities. Work can continue while you navigate within the running app, but closing Atraium can interrupt it. Unfinished assignments do not restart automatically.
- **Stopping does not undo completed actions.** Check saved results and external changes before retrying. Wait for work to finish closing before reusing a workspace, changing its settings or retrying a blocked deletion.
- **File tools have full access by default within your operating-system permissions.** Room and workspace settings can require directory access requests. On Windows, these requests take effect immediately rather than opening another approval dialog. These controls do not grant administrator privileges or sandbox commands, plugins or other software. See [Tools and access](https://github.com/daemosofchaos/Atraium-Preview/blob/main/docs/workspaces-and-tools.md).
- **Review Skills before use or sharing.** Import from trusted sources and remove confidential project details from workflow drafts. Skills do not change tool or file access.

## Known limitations

This is preview software, not a guarantee of production readiness or unattended safety.

- Model and tool support varies by provider. A successful connection does not guarantee reliable work with every tool or large request.
- Live response updates require a supported GPT-6 connection and are not available in voice chats or Supervisor assignments.
- Skills support written instructions and text references; bundled scripts are not run. Important results still need your review.
- Windows and Android do not offer identical tool coverage. Mobile suspension can interrupt background work and downloads.
- Large documents, media and slower storage can still take time to prepare.

See the [full preview scope](https://github.com/daemosofchaos/Atraium-Preview/blob/main/PREVIEW.md) and [Troubleshooting](https://github.com/daemosofchaos/Atraium-Preview/blob/main/docs/troubleshooting.md).

## Costs and credentials

**Atraium is a bring-your-own-model application. It does not include provider credentials, model credits, a token allowance or hosting. You are responsible for charges incurred through your connected accounts and services.**

- Chat, live updates, Skills, research, OCR, images, video, speech and paid integrations can create charges. Consumer chat subscriptions do not necessarily include API credits.
- Independent assistants, Supervisor teams and longer projects may make many model and tool calls. Set **provider-side budgets, quotas and hard spending limits where available** before starting. Team request limits, spending alerts and Atraium's usage display are not hard spending controls.
- Local models can avoid hosted per-token charges, but hardware, electricity, storage and rented servers still use resources. A local Chat model does not make other hosted capabilities free.
- Keep API keys private. Cancellation may not prevent charges for requests already accepted by a provider.

**Provider-side billing records are authoritative.** Read [Token usage and provider billing](https://github.com/daemosofchaos/Atraium-Preview/blob/main/TOKEN-USAGE-AND-BILLING.md) before connecting paid services.
