# Atraium 0.2.2 Preview 1

Atraium 0.2.2 Preview 1 improves usage visibility, provider-request reliability, and Workspace controls.

## Highlights

### Usage and cost visibility

- Review model and provider usage for a Workspace or across Atraium.
- See token totals and other supported usage measurements when available.
- Filter usage by time, Room, Workspace, provider, model, operation, and outcome.
- View estimated costs when compatible pricing information has been configured.
- Keep different currencies separate rather than combining unlike amounts.

Provider billing records remain authoritative. Estimates may differ from invoices because of taxes, discounts, regional pricing, account agreements, or information not supplied by the provider.

### More resilient provider requests

- Improved handling of temporary provider limits and interruptions.
- Optional request pacing for providers with strict quotas.
- Clearer status while Atraium waits before trying a temporary failure again.
- Better recovery when a tool or computer-use step fails.

### Refined Workspaces

- Edit a Workspace name, brief, and instructions from Workspace settings.
- Reset instructions to the selected template when needed.
- Apply updated Workspace instructions to the next message.
- Improved Workspace-list reliability after creating a new Workspace.

## Platforms

- **Windows desktop:** recommended preview experience.
- **Android and Web:** not included in this release.

## Important notes

- This is preview software and may contain breaking issues.
- Usage and cost information depends on what each provider reports.
- Provider availability, model access, regions, quotas, and pricing vary.
- Tool behaviour depends on the selected model and enabled permissions.
- Support is best-effort.

## Costs and credentials

Atraium does not include provider credentials, model credits, or token allowances. You are responsible for usage and charges from the providers and services you configure. Set provider-side limits and review [Token usage and provider billing](https://github.com/daemosofchaos/Atraium-Preview/blob/main/TOKEN-USAGE-AND-BILLING.md) before using paid credentials.
