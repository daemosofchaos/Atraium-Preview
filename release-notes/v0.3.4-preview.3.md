# Atraium 0.3.4 Preview 3

Atraium 0.3.4 Preview 3 is a small Word document-generation fix for [Preview 2](https://github.com/daemosofchaos/Atraium-Preview/releases/tag/v0.3.4-preview.2). It is recommended for all Preview 2 users who create Word documents.

## What changed

- Fixed an issue where a generated notice, tip, warning, or other highlighted callout could visually merge into a table placed immediately before or after it.
- Generated callouts and nearby tables now remain distinct document blocks, whether the table appears before or after the callout.
- Improved handling of requested spacing after generated callouts and code blocks.
- Improved compatibility of generated Word document formatting across supported document editors.

## Platforms

- **Windows desktop:** recommended preview experience.
- **Android:** early sideloaded preview for Android 7.0 or later, supporting arm64-v8a devices and x86_64 emulators.
- **Web, macOS, and iOS:** not included in this preview.

## Important notes

- This is preview software and may contain breaking issues.
- Regenerate an affected Word document after updating to apply the formatting fix.
- Existing documents are not changed automatically.
- Support is best-effort.
