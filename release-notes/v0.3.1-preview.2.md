# Atraium 0.3.1 Preview 2

Atraium 0.3.1 Preview 2 is a stability update for [Preview 1](https://github.com/daemosofchaos/Atraium-Preview/releases/tag/v0.3.1-preview.1). It is recommended for all Preview 1 users.

## What changed

- Improved reliability for multi-step assistant workflows that use tools with compatible OpenAI Responses API providers.
- Prevented activity-display problems from interrupting otherwise successful tool work.
- Corrected first-run model-profile setup on new installations.
- Preserved existing model profiles and settings when updating from an earlier preview.
- Improved general conversation and usage-estimation stability.

## Platforms

- **Windows desktop:** recommended preview experience.
- **Android:** early sideloaded preview for Android 7.0 or later, supporting arm64-v8a devices and x86_64 emulators.
- **Web, macOS, and iOS:** not included in this preview.

## Important notes

- This is preview software and may contain breaking issues.
- Provider features, model behaviour, quotas, regions, and pricing vary.
- Tool behaviour depends on the selected model, configured permissions, and available platform capabilities.
- Start a new conversation if a conversation affected before this update does not recover normally.
- Support is best-effort.
