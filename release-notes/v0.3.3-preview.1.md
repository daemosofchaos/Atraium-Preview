# Atraium 0.3.3 Preview 1

Atraium 0.3.3 Preview 1 expands local and open-weight image generation while making model-provider configuration clearer and safer.

## Highlights

### Local image-generation servers

- Added **ComfyUI** image-generation profiles for local or hosted workflow-based image servers.
- Configure a ComfyUI profile with its server address and an exported workflow, then use it with compatible image models such as Qwen Image, Flux, SDXL, and other supported workflows.
- Added **Stable Diffusion WebUI** profiles for compatible local and hosted servers.
- Stable Diffusion profiles support compatible text-to-image, image-to-image, and mask-based image editing workflows.
- Local image-server profiles can use an optional credential when a reverse proxy or hosted server requires one.

### Purpose-driven provider profiles

- Each provider profile now has a clear purpose: **Text generation**, **Embeddings**, **Image generation**, **Text to audio**, **Audio to text**, or **Audio to audio**.
- The provider editor now shows only settings that apply to the selected purpose and provider.
- Image-only profiles no longer show Chat Completions or Responses API options.
- Local image servers no longer require a chat model target or an API key for normal local use.
- Labels and connection guidance now match the selected capability, including image, audio, transcription, and realtime targets.

### Safer profile editing

- Changing a provider or purpose now preserves the existing endpoint, model, workflow, advanced settings, and credential draft while you edit.
- Atraium identifies profiles that need a purpose review instead of silently replacing their configuration.
- Existing multi-purpose profiles remain available for compatibility and are clearly identified when they should be split into separate provider profiles.
- Selecting **Apply provider defaults** remains the explicit way to replace a profile with provider defaults.

## Platforms

- **Windows desktop:** recommended preview experience.
- **Android:** early sideloaded preview for Android 7.0 or later, supporting arm64-v8a devices and x86_64 emulators.
- **Web, macOS, and iOS:** not included in this preview.

## Important notes

- This is preview software and may contain breaking issues.
- Local image generation requires a separately installed and configured compatible server and model.
- Generated image quality, editing support, available dimensions, and generation speed depend on the selected model, workflow, server, and hardware.
- Keep locally hosted image servers private or protect them with appropriate network and authentication controls.
- Support is best-effort.
