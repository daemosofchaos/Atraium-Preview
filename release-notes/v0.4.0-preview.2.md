# Atraium 0.4.0 Preview 2

Atraium 0.4.0 Preview 2 focuses on more reliable conversations: safer follow-ups after Stop, cleaner quoted replies, and saved progress when the app closes unexpectedly. It follows [Preview 1](https://github.com/daemosofchaos/Atraium-Preview/releases/tag/v0.4.0-preview.1).

## What changed

### Continue after Stop

- Fixed follow-up messages failing after **Stop** when using OpenAI Responses mode. Partial answers and completed tool results remain available to the conversation.

### Quote without bringing back old prompts

- Fixed **Ask about this** restoring an already-sent message alongside the selected quote while an assistant was responding.
- Selected quotes append to your actual unsent draft. New drafts and multiple quotes remain intact when the current response finishes or is stopped.
- **Enter** and the Send button now consistently use your latest typed text. Sending while a Workspace is still loading leaves the draft untouched.

### Recover saved progress

- In-progress text conversations now save partial answers, reasoning, returned tool results, and generated artifacts as work proceeds, including during long tool tasks and Computer Use Handoffs.
- Reopening an affected Workspace after an unexpected shutdown shows saved progress with a clear interruption notice. Completed tool results are retained; unfinished tool outcomes are flagged for verification.

### Smoother background saving

- Improved responsiveness while saving conversations with large attachments or extensive tool activity.
- Failed background saves retry with pauses and fewer repeated alerts. Repeated saves avoid duplicating conversation messages and usage records.

## Platforms

- **Windows desktop:** recommended preview experience.
- **Android:** early sideloaded preview for Android 7.0 or later, supporting arm64-v8a devices and x86_64 emulators.
- **Web, macOS, and iOS:** not included in this preview.

## Important notes

- This is preview software; support is best-effort.
- Recovery preserves saved progress, not automatic job resumption. Recent unsaved changes can still be lost; responses lost before this update cannot be reconstructed.
- Verify unfinished tool outcomes before repeating an interrupted action. **Stop** does not undo completed actions.
- Parallel background work remains limited to text chats. Keep Atraium open for work to continue; simultaneous voice sessions and cross-assistant delegation are not supported.
