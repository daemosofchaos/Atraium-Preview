# Atraium 0.3.4 Preview 2

Atraium 0.3.4 Preview 2 is a reliability and document-formatting update for [Preview 1](https://github.com/daemosofchaos/Atraium-Preview/releases/tag/v0.3.4-preview.1). It is recommended for all Preview 1 users.

## What changed

### Rooms and Workspaces

- Fixed Room names and other saved Room details reverting in navigation after sending a message.
- Editing a Room now updates its name in the navigation immediately.
- Cloned Rooms now include a ready-to-use default Workspace, so notes, tasks, and other Workspace features are available immediately.
- Room-level tool-routing preferences now remain consistent when working across multiple Workspaces in the same Room.
- Creating a Workspace now starts with a **Blank workspace** by default. Blank Workspaces inherit the Room instructions and do not silently apply a template personality.
- Workspace templates remain available whenever you want a specialised starting point.
- Pinned Rooms now use a single highlighted pin control instead of showing a duplicate pin indicator.

### Better Word document formatting

- Fixed separate numbered lists in generated Word documents continuing numbering from an earlier list. Each new list now starts at its intended number.
- Corrected generated bullet lists so they display standard round bullet points rather than broken square characters.
- Added comfortable padding inside generated table cells, so text no longer sits against column borders.
- Improved compatibility of generated table formatting with Word document validation.

## Platforms

- **Windows desktop:** recommended preview experience.
- **Android:** early sideloaded preview for Android 7.0 or later, supporting arm64-v8a devices and x86_64 emulators.
- **Web, macOS, and iOS:** not included in this preview.

## Important notes

- This is preview software and may contain breaking issues.
- Existing Room and Workspace content is preserved when updating.
- Blank Workspaces inherit Room instructions. Choose a template only when you want its dedicated structure and guidance.
- Support is best-effort.
