# Atraium 0.3.1 Preview 5

Atraium 0.3.1 Preview 5 improves reasoning controls for compatible models. It follows [0.3.1 Preview 4](https://github.com/daemosofchaos/Atraium-Preview/releases/tag/v0.3.1-preview.4).

## What changed

- Selected reasoning-effort levels are now applied more consistently with compatible reasoning models.
- Atraium no longer applies an unintended reasoning level when no reasoning effort is configured.

## Platforms

- **Windows desktop:** recommended preview experience.
- **Android:** early sideloaded preview for Android 7.0 or later, supporting arm64-v8a devices and x86_64 emulators.
- **Web, macOS, and iOS:** not included in this preview.

## Important notes

- This is preview software and may contain breaking issues.
- Available reasoning controls depend on the selected model and provider.
- Support is best-effort.
