# Atraium 0.5.0 Preview 1

Atraium 0.5.0 Preview 1 brings coordinated assistant work to your projects, introduces guided setup and first-visit tours, and makes opening saved conversations clearer and more responsive.

## Features and improvements

### Delegate projects with Supervisor workspaces

- **Turn a workspace into a Supervisor.** Enable Supervisor delegation in Workspace settings, then give your assistant an objective. It can create specialist workspaces, delegate focused assignments, collect their results and bring the work together within the same Room.
- **Build teams within teams.** When nested supervision is enabled, a worker can coordinate its own specialists. Shared limits on team size, depth, concurrent work, model requests and duration keep the whole project bounded.
- **Follow the work as it happens.** The assignment tree shows each branch, its progress, results and any errors. Open a worker's workspace to review its conversation without stopping other work.
- **Stay in control.** Pause a response and resume it when ready, stop one branch without cancelling its siblings, or stop all delegated work. Workers respect the tools and file access available to them; delegation does not enable disabled tools or expand their access.

### Get started with guidance, not guesswork

- **A guided first launch.** Spotlight tips highlight the real controls, explain what they do, and walk you through connecting Chat, choosing file access and opening your first Room. A responsive layout makes better use of the available window width.
- **Use the profiles already provided.** Start with the existing Chat profile. Utility is now optional: when no usable separate Utility profile is configured, Chat handles summaries and supporting tasks. If you choose a separate Utility profile, the tour guides you through its connection details too.
- **Set up at your own pace.** Hide tips, skip setup or exit at any stage. Progress is saved so you can return later. The welcome screen also offers **Import backup** to open Backup & Restore.
- **Learn each area when you need it.** First-visit guides introduce Settings, Model providers, Room and workspace settings, Rooms, workspaces, MCP servers and Plugins. Revisit them from **Settings → Tutorials and guides**, keeping your working views focused on the task at hand. Guidance uses clearer, plain-language explanations throughout.

### Open saved conversations with confidence

- **Less work when switching conversations.** Long conversations open with their latest messages first; earlier messages remain available as you scroll upward. Returning to a workspace reuses its conversation and unsent draft during the same app session.
- **A clear loading state.** Atraium shows that your conversation is loading and keeps chat actions unavailable until the saved history is ready. An unfinished load no longer looks like a new, empty chat. If loading fails, **Retry loading** lets you try again.
- **Quicker initial positioning.** The chat reaches its latest messages with less waiting. Late-loading content can settle in the background, while scrolling back through history takes precedence.
- **Your first Room appears immediately.** A newly created default Room now appears in the left navigation without reloading Atraium.

## Platforms

- **Windows desktop:** recommended preview experience.
- **Android:** early sideloaded preview for Android 7.0 or later. Local model servers must be reachable from the device; heavy image and video inference runs on a hosted service or remote server, not on the phone.
- **Web, macOS and iOS:** not included in this preview distribution.

## Important notes

- This is preview software. **Back up important data before upgrading.** Provider availability and capabilities vary.
- **Supervisor delegation is opt-in.** Its limits are shared across the team, including nested workers. Request limits are not a currency spending cap, and each assistant can incur provider charges. Work continues while you navigate within the running app, not as an always-on service after Atraium closes. Interrupted assignments are not automatically restarted.
- **Stopping work does not undo completed actions.** Review saved results and external changes before retrying an interrupted assignment. Room or workspace deletion is blocked while cleanup is pending, keeping saved conversations intact. Retry deletion once cleanup finishes.
- **File tools have full access by default within your operating-system permissions.** Room and workspace settings can require directory access requests. On Windows, these requests grant access immediately rather than opening a separate approval dialog. File-tool controls do not grant administrator privileges or sandbox terminal commands, plugins or other software. Give workers separate file responsibilities when possible.
- **Tours do not send sample conversations, run connection tests or download models automatically.** Existing users are not forced through first-start setup. Replaying a guide does not reset saved connections or work. New credentials are saved only when you choose the relevant Save action.
- **Backup restore replaces the data covered by the archive rather than merging it.** Review the restore confirmation; API keys must be re-entered. Opening Import backup does not start a restore.
- Larger documents, images or slower storage can still take time to prepare. Loading improvements do not impose a fixed total opening time. Mobile suspension can pause background work, tracking and downloads.

## Costs and credentials

**Atraium is a bring-your-own-model application.** It does not include provider credentials, model credits, a token allowance or hosting. You are responsible for charges incurred through the accounts and services you configure.

- Chat, research, OCR, images, video, speech and paid integrations can incur separate charges. A consumer ChatGPT, Claude or Gemini subscription does not necessarily include API credits. A local Chat model does not make other hosted capabilities free.
- Supervisor teams, longer projects and follow-up work can involve many model and tool calls. Set **provider-side budgets, quotas and hard spending limits where available** before starting. Alerts and Atraium's usage display are not hard spending controls.
- Local models can avoid hosted per-token charges, but hardware, electricity, storage and rented servers can still cost money. Hosted services receive the prompts and selected content needed for their features.
- Keep API keys private. Do not include credentials in prompts, screenshots or public bug reports. Cancellation may not prevent charges for requests already accepted by a provider.

**Provider-side billing records are authoritative.** Review [Token usage and provider billing](https://github.com/daemosofchaos/Atraium-Preview/blob/main/TOKEN-USAGE-AND-BILLING.md) before connecting paid services.
