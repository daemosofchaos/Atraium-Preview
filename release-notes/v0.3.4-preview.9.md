# Atraium 0.3.4 Preview 9

Atraium 0.3.4 Preview 9 makes streamed answers and reasoning easier to follow, improves response layout, and corrects model token-budget handling. It follows [Preview 8](https://github.com/daemosofchaos/Atraium-Preview/releases/tag/v0.3.4-preview.8).

## What changed

### Clearer response layout

- Separate text sections returned by supported providers now receive appropriate paragraph spacing, preventing adjacent sections and headings from running together.
- Headings within a response have clearer visual separation. Formatting is preserved across saved conversations without changing the underlying response text or breaking code blocks, links, and tables.

### Smoother streaming text

- Newly arriving answer text now fades into view instead of appearing abruptly. The same effect applies to reasoning while the **Reasoning** section is expanded and still streaming.
- Existing text stays settled. Opening or reopening Reasoning, loading completed messages, and finishing a response do not replay the animation.
- The fade respects reduced-motion preferences and is disabled in forced-colors accessibility mode.

### Model limits and compatibility

- Fixed an issue where chat initialization could overwrite the configured model input-token limit with a built-in default. The configured limit now remains in effect.
- Added recognition of GPT-6-series model identifiers for reasoning settings, token estimation, and input/output budget defaults.
- New OpenAI-compatible chat configurations default to `gpt-6.1-sol`. Existing configured model selections are unchanged; choose a model available from your provider.

## Platforms

- **Windows desktop:** recommended preview experience.
- **Android:** early sideloaded preview for Android 7.0 or later, supporting arm64-v8a devices and x86_64 emulators.
- **Web, macOS, and iOS:** not included in this preview.

## Important notes

- This is preview software and may contain breaking issues.
- Model availability, reasoning output, and supported limits depend on your provider. Configure token limits to match the model and endpoint you use.
- Support is best-effort.
