# Atraium 0.3.4 Preview 8

Atraium 0.3.4 Preview 8 improves automatic conversation continuation, corrects misleading response-status feedback, and makes device links open reliably without leaving Atraium. It is recommended for [Preview 7](https://github.com/daemosofchaos/Atraium-Preview/releases/tag/v0.3.4-preview.7) users, especially those working through long, tool-heavy conversations.

## What changed

### More reliable conversation continuation

- Fixed an issue where automatic continuation could unnecessarily restart a Responses API conversation and resend excessive earlier activity, causing the next response to fail.
- Successful continuations now retain the existing conversation and send only the new information needed to continue.
- Restored server-side context compaction in supported Responses API configurations.
- When a conversation must be rebuilt, its history now passes through the existing compaction process using the configured model input capacity. Stored conversation history remains available.

### Accurate response-status feedback

- Successful continuation messages without accompanying text now display **Continued in the next message.** instead of **Response failed.**
- Other completed responses without text now display **Completed without a text response.**
- Successful text-free responses use neutral information styling; genuine response failures retain their error indication.

### Device links open outside Atraium

- Local file links now open in the device's associated application rather than attempting to replace the Atraium chat view.
- Fixed Windows file-opening failures affecting otherwise valid local file links.
- Improved handling of file links written with Windows-style separators.
- External web and application links launch through the device while Atraium stays open. Internal app navigation and document anchors continue to work normally.
- Missing files or unavailable applications display an explanatory message instead of navigating away from the app.

## Platforms

- **Windows desktop:** recommended preview experience.
- **Android:** early sideloaded preview for Android 7.0 or later, supporting arm64-v8a devices and x86_64 emulators.
- **Web, macOS, and iOS:** not included in this preview.

## Important notes

- This is preview software and may contain breaking issues.
- Server-side context compaction depends on support from the configured provider and model.
- Successive continuation checks passed on the tested configuration; please report any remaining intermittent failures.
- Support is best-effort.
