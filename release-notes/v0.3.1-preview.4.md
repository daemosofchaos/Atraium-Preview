# Atraium 0.3.1 Preview 4

Atraium 0.3.1 Preview 4 improves the reliability of model-triggered actions. It follows [0.3.1 Preview 3](https://github.com/daemosofchaos/Atraium-Preview/releases/tag/v0.3.1-preview.3).

## What changed

- Improved compatibility when models return valid action options in alternative text formats.

## Platforms

- **Windows desktop:** recommended preview experience.
- **Android:** early sideloaded preview for Android 7.0 or later, supporting arm64-v8a devices and x86_64 emulators.
- **Web, macOS, and iOS:** not included in this preview.

## Important notes

- This is preview software and may contain breaking issues.
- Model and provider capabilities vary.
- Support is best-effort.
