# Atraium 0.4.1 Preview 1

Atraium 0.4.1 Preview 1 brings visual answers into conversations, adds more flexible PDF reports, and improves responsiveness during document processing and background saving. It follows [0.4.0 Preview 2](https://github.com/daemosofchaos/Atraium-Preview/releases/tag/v0.4.0-preview.2).

## What changed

### Visual answers you can reuse

- Assistants can now create inline charts, scatter plots, heatmaps, metric cards, timelines, comparisons, process flows, histograms, and waterfalls. Metric cards support supplied trends and actual-versus-target bars.
- Visuals remain in saved conversations. Use **Show data**, **Copy CSV**, or **Ask about this** to inspect values, reuse data, or add a follow-up to your draft without sending it automatically.
- **Copy image** and **Save PNG** export clean visuals for documents, with a white background by default and an optional **App theme** style. Metric spacing, waterfall keys, and comparison wrapping adapt to their content.

### More creative PDF reports

- Assistants can generate styled PDFs from ordinary HTML or a local HTML file, including tables, columns, local fonts, images, and static graphics. This is now the preferred desktop PDF creator and is easier for assistants to find.
- Automatic print defaults provide recurring page margins, headings kept with following content, repeated table headers, row-aware pagination, and text wrapping. Custom page styles remain supported, with an opt-out for fully controlled layouts.

### A smoother conversation experience

- Large PDF attachments are processed in the background, reducing freezes while preparing documents to send. Improved cancellation and text-only reads avoid unnecessary document processing.
- Reduced pauses during background conversation saving, particularly in long, tool-heavy chats and when several Workspaces are active.

## Platforms

- **Windows desktop:** recommended preview experience.
- **Android:** early sideloaded preview for Android 7.0 or later, supporting arm64-v8a devices and x86_64 emulators.
- **Web, macOS, and iOS:** not included in this preview.

## Important notes

- This is preview software; support is best-effort. Model and provider capabilities vary.
- HTML-to-PDF requires installed desktop Edge or Chrome. Android retains the existing PDF generator. Desktop legacy PDF authoring is disabled by default and can be enabled in Room or Workspace tool settings; explicit saved choices are preserved.
- HTML reports use static content and local or embedded assets; remote resources and scripts are blocked. Visuals are saved snapshots, not live dashboards.
