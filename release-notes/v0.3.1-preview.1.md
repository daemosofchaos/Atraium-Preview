# Atraium 0.3.1 Preview 1

Atraium 0.3.1 Preview 1 expands the model-to-assistant experience across Windows and Android. It introduces a refreshed interface, easier model configuration, stronger project organisation, and broader provider visibility.

## Highlights

### Android preview

A signed Android APK is now available for Android 7.0 or later, supporting arm64-v8a devices and x86_64 emulators. Android remains an early sideloaded preview; Windows desktop is the recommended target for the broadest tool coverage.

### Refreshed conversations and navigation

- Cleaner assistant and user messages with clearer reasoning and tool-activity presentation.
- More dependable navigation in long conversations.
- Improved attachment cards, previews, and actions at desktop and mobile sizes.
- Redesigned Room, Workspace, task, note, artifact, and attachment surfaces.
- Faster access to recent Rooms, management pages, and model providers.

### Light, Dark, and System themes

Choose a Light, Dark, or System appearance. The preference applies immediately and is retained across restarts.

### Easier model management

- Create and manage reusable model profiles from one focused interface.
- See which profiles power the main assistant and specialist capabilities.
- Start from templates for OpenAI-compatible, Anthropic, and Google Gemini providers.
- Test a configured connection before using it for normal work.
- Switch the active Workspace model from the conversation without rebuilding the assistant or project.

Connection tests make a real provider request and may incur a small charge.

### Better reasoning and usage visibility

- Improved handling of reasoning produced by compatible models.
- Broader provider-reported token-usage capture across supported providers.
- Clearer usage information for monitoring configured models and costs.

### General quality improvements

This release also improves responsive layouts, keyboard access, reduced-motion support, setup, administration, provider configuration, startup behaviour, and large-conversation performance.

## Platforms

- **Windows desktop:** recommended preview experience.
- **Android:** early sideloaded preview.
- **Web, macOS, and iOS:** not included in this preview.

## Important notes

- This is preview software and may contain breaking issues.
- Provider features, parameters, usage reporting, quotas, regions, and pricing vary.
- A successful connection test does not guarantee that every model capability is supported.
- Switching the active model starts a fresh provider conversation.
- Support is best-effort.
